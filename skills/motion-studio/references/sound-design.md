# Звуковой дизайн моушн-ролика

Ролик без звука в ленте выглядит недоделанным. Звук делается **сразу при сборке**, без отдельной просьбы, и ставится от тех же кадров, что и анимация.

## 1. Подключение (Remotion)

```bash
npx remotion add @remotion/media                              # <Audio>
mkdir -p scripts && cp <skill>/templates/remotion/make-sfx.mjs scripts/
cp <skill>/templates/remotion/sfx.tsx src/components/sfx.tsx  # + в index.tsx: export * from "./sfx";
node scripts/make-sfx.mjs 40                                  # public/sfx/*.wav; 40 = длина музыки, с
```

Звуки синтезирует код, без сэмплов, поэтому они свои: без лицензий, одинаковые при каждом запуске, можно класть в публичный репо. Набор:

| Файл | Когда |
|---|---|
| `key-1…4`, `key-space`, `key-enter` | печать в поле ввода, терминале, чате (4 варианта щелчка по кругу) |
| `whoosh`, `whoosh-soft` | появление титра, смена сцены, пролёт объекта |
| `pop`, `pop-high` | появление карточки, бейджа, иконки, пузыря чата |
| `hit` | «приземление», акцентное слово, логотип, финальный удар |
| `ding` | успех, «готово», галочка, уведомление |
| `riser` | нарастание перед кульминацией или финалом |
| `bed` | музыкальная подложка: тёплый пэд Am–F–C–G, лёгкая пульсация 120 BPM |
| `beat` | бит 120 BPM на 24 с: бочка в каждую долю, хлопок на 2 и 4, хэты, бас. Удар = 15 кадров при 30 fps, склейки ставить на кратные 15. Для динамичных промо; «дроп» = заглушить бит на 12–15 кадров перед финалом |

Вместо имени можно передать URL: `https://remotion.media/` + `whoosh.wav`, `whip.wav`, `switch.wav`, `mouse-click.wav`, `ding.wav`, `shutter-modern.wav`, `page-turn.wav`, `vine-boom.wav`… Реальные записи: mixkit.co/free-sound-effects, pixabay.com/sound-effects, github.com/kapishdima/soundcn. Скачанные звуки кладутся в `public/sfx/`. Перед публикацией проверить их лицензию.

## 2. Компоненты (`src/components/sfx.tsx`)

```tsx
import { Sfx, TypingSfx, WordSfx, MusicBed } from "./components";

<Sfx s="pop" at={14} volume={0.4} />            // один звук в локальный кадр 14 текущей Sequence
<Sfx s="whoosh" at={cut} />                      // whoosh/riser сами сдвигаются раньше (SFX_LEAD), чтобы ПИК пришёлся на `at`
<Sfx s="pop" at={15} rate={0.85} />              // rate: ниже = глубже, тот же звук звучит по-новому

// Печать: те же text/start/cps, что у <TypingInput>. Щелчок на каждый символ + Enter в конце
<TypingInput text={cmd} start={18} cps={26} … />
<TypingSfx  text={cmd} start={18} cps={26} volume={0.32} />

<WordSfx text={title} start={4} perWord={4} />   // whoosh-soft на каждое слово BlurWords (стиль спек-рекламы)
<MusicBed durationInFrames={total} volume={0.17} duck={[[300, 420]]} />  // fade in/out; duck: −10 дБ под голос
```

`charFrame(i, start, cps, fps)` возвращает кадр, в котором `TypingInput` показывает символ №i. Через него звук привязывается к своим анимациям печати.

## 3. Какой звук на какое событие

| На экране | Звук | Громкость (volume) |
|---|---|---|
| Смена сцены (hard cut) | `whoosh` на кадр склейки | 0.4 |
| Заголовок проявляется | один `whoosh` на заголовок (в спек-рекламе — `WordSfx` на каждое слово) | 0.35–0.45 |
| Карточка/бейдж/иконка появилась | `pop` / `pop-high` | 0.2–0.4 |
| Печать | `TypingSfx` + Enter | 0.3 |
| Объект «приземлился», логотип, акцент | `hit` | 0.6–0.7 |
| Успех, «готово», галочка | `ding` (через 3–4 кадра после hit) | 0.4 |
| Перед финалом, кульминацией | `riser`, пик на кадре удара | 0.45 |
| Счётчик цифр | тихие `key-*` раз в 2–3 кадра, в конце `ding` | 0.15 |
| Под всем роликом | `MusicBed`, без голоса 0.15–0.2, под голосом −15 дБ (duck) | — |

## 4. Правила, из-за которых звучит «как у популярных»

1. **Тайминг от кадров анимации, а не на слух.** Ударные звуки (pop, hit, key) идут ровно в кадр события. У whoosh и riser пик ставится на событие, начало раньше (это делает `lead`).
2. **Разнообразие.** Один и тот же файл подряд режет ухо. Помогают 4 щелчка по кругу, разброс громкости ±20 % и высоты ±6 % (так работает `TypingSfx`), `rate` для повторов pop.
3. **Иерархия.** Голос громче всего, за ним акценты (hit, whoosh), потом мелочь (pop, клавиши), ниже всех музыка. Мелочь не должна спорить с акцентом.
4. **Не озвучивать каждую мелочь.** Звук нужен на событие, которое зритель должен заметить. Подпись, которая выезжает вслед за карточкой, озвучивать не надо.
5. **Тишина тоже приём.** На 2–4 кадра перед hit можно убрать музыку.
6. **Мастер.** После рендера: `bash scripts/master-audio.sh out/raw.mp4 out/final.mp4`. Норма −14 LUFS (±1), пик ≤ −1 dBTP. Видео копируется без перекодирования.

## 5. Проверка (звук не слышно — проверять глазами)

- `ffprobe` показывает дорожку `aac`, её длительность равна длительности видео.
- Громкость: `ffmpeg -i final.mp4 -af ebur128=peak=true -f null - 2>&1 | grep -A15 Summary`, ожидается I ≈ −14 LUFS, Peak ≤ −1.
- Синхрон: осциллограмма `ffmpeg -ss A -t B -i final.mp4 -filter_complex "aformat=channel_layouts=mono,showwavespic=s=1600x300:scale=sqrt" -frames:v 1 wave.png`. Пачки щелчков должны совпадать с отрезками печати, всплески с кадрами склеек (время = кадр / fps).
- Форма каждого звука: `showspectrumpic` (без `drawtext`: на Windows ffmpeg падает на fontconfig).
- Если щелчки не выступают над музыкой, убавить `MusicBed`, а не прибавлять SFX.

Пример целиком: `src/Tutorial.tsx` в репозитории motion-studio, видео-инструкция со звуком (`examples/tutorial.mp4`).
