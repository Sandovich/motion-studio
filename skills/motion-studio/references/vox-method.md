# Вокс-эксплейнер — метод целиком

Рецепт «объяснялки в стиле Vox»: голос диктора + коллаж из гравюр и вырезок на бумаге, 30 с – 10 мин, 9:16 или 16:9. Собран из разбора скилла vox-animation (Mr. Pynk, 05.10.2026), рилса-демо и нашего `charlie-motion-graphics/skills/vox-explainer`. Исходники разбора лежат локально в `research/vox_2026-10/` (сюда не копируются: у оригинала нет лицензии).

Два пути, визуальный язык один:

| | **A. Кодом (по умолчанию, 0 ₽)** | **B. Видеогенерация (платно, только после «да» с ценой)** |
|---|---|---|
| Картинка | Remotion: PD-гравюры/архивные фото + вырезка + бумага/полутон/маркер кодом | ключ стиля (1 картинка) + по видео-промпту на сцену в Seedance 2.5 / Kling / Veo через Higgsfield MCP |
| Голос | edge-tts (бесплатно) или живой/клонированный голос | то же |
| Монтаж | Remotion, синхрон к словам по faster-whisper | ffmpeg-склейка N×10 с, текст поверх кодом |
| Когда | почти всегда | нужна «живая» органика: щупальца, пружина, толпа, FPV-полёт по диораме |

---

## 1. Сценарий (общий для обоих путей)

**Сцена = 10 секунд = одна строка диктора на 18–20 слов** (по-русски ≈ 15–18 слов, слова длиннее). 60 с = 6 сцен. Числа писать словами.

Структура:
1. **Холодный старт:** самый удивительный факт, ровно, без «привет».
2. **Ставки:** почему это важно.
3. **Доказательства:** одна идея на сцену, конкретная цифра, дата или место, по нарастающей.
4. **Поворот:** «но вот что на самом деле…».
5. **Развязка + кикер**, который заново объясняет сцену 1.

Тон: любопытный, точный, чуть ироничный. Объясняет, а не хайпит.

**Задумать до того, как писать текст:**
- **Сквозной объект:** есть в каждой сцене и меняется по нарастающей (у PYNK: банк → осьминог → сейф → паника).
- **Вопрос-крючок,** ответ на который даётся в самом конце.
- **Кадр-«открытие»:** один кадр, который запомнят (башня закручивается пружиной).
- **Удар каждые ~3 с:** штамп, хлопок, вспышка, щелчок.
- **Fake-oner:** каждая сцена — одно непрерывное движение камеры, которое начинается и кончается смазом. Тогда склейки читаются как один план.

**Факты:** ресёрч обязателен, каждая цифра сверяется по двум источникам, список источников идёт в подпись к посту. Если не уверен, лучше расплывчатая правда, чем точная выдумка.

**Ворота перед производством:** показать таблицу брифа (тема и угол, сквозной объект, стиль, длина и число сцен, формат, голос) и строки «Сцена 1…N». Ждать «да». Пользователь может переписать любую строку.

## 2. Визуальный язык (на сцену 2–3 приёма, иллюстрировать мысль, а не слова)
- **Бумага всегда:** белая мятая, крафт, миллиметровка, газета, плюс зерно и полутон.
- **Вырезки:** ч/б гравюры и архивные фото с рваной белой каймой. Это элементы коллажа: кадр целиком никогда не «живое видео».
- **1–2 цветных акцента на ч/б:** красно-оранжевый, жёлтый круг-солнце, синий. Палитра одна на весь ролик, доминирующий цвет — один на сцену. Вариант: дуотон (Капитолий синим + полутон).
- **Метафора-объект:** банк-осьминог, сейф и паника, башня-пружина.
- **Маркер:** круг сам обводит вырезку, стрелки, подчёркивания, штрихи.
- **Инфографика без подписей:** растущие столбики, рисующаяся линия, распадающийся пирог. Цифры, если нужны, — кодом.
- **Карты:** маршрут рисуется, точки пульсируют, регионы заливаются.
- **Цензурные полосы** на глазах (стиль «диорама»), **прожектор-виньетка**, **сравнение масштаба** (размножение в ряды, маленький рядом с огромным).
- **Движение:** резкий ease-out с перелётом, медленный наезд на «слушайте внимательно», whip-pan или перелист между идеями, параллакс слоёв. Всегда что-то движется, громкое — только одно.

Два «дома» стиля:
- **Mixed Media (классика Vox):** светлый, тёплый жёлтый / off-white / тёмно-синий / коралловый. Текста в кадре нет, весь текст — кодом.
- **Paper Diorama (кино-документалка):** мир из старых газет сепией, фигуры в костюмах с цензурными полосами, ОДИН жжёно-оранжевый акцент, высокая печать, вольфрамовый свет, тилт-шифт, FPV-камера со speed-ramp. Для денег, власти, геополитики, «расследований». Одна надпись на реквизите на сцену (1–2 слова).

## 2а. Референсы с Pinterest (бесплатно, без логина и ключа)
Скрипт `scripts/pinterest.py` из репозитория motion-studio (только стандартная библиотека + Pillow):
```
python scripts/pinterest.py search "vox style paper collage animation" -n 40 -o refs/vox
python scripts/pinterest.py board https://www.pinterest.com/<user>/<board>/ -n 100 -o refs/board
python scripts/pinterest.py pin https://www.pinterest.com/pin/<id>/ -o refs/one --orig
python scripts/pinterest.py similar <id|ссылка> -n 30 -o refs/similar
```
В папке — картинки `NN_<id>`, `pins.tsv` (ссылка на пин, домен и ссылка-источник, описание, размер) и `sheet.jpg` с номерами: смотреть лист и выбирать по номерам. По умолчанию качается 736 px, оригиналы — `--orig`.
- Хорошие запросы: `vox style collage`, `editorial collage animation`, `paper cutout collage`, `halftone collage poster`, `vintage engraving cutout`, `mixed media collage motion design`, `paper diorama newspaper`, `styleframe collage`; плюс тема ролика на английском.
- Для чего: (1) мудборд и выбор палитры и композиции перед ключом стиля; (2) референс в Seedance/Nano Banana (путь B); (3) разбор приёмов (что вырезано, где акцент, как лежит текст).
- **Права:** картинки с Pinterest чужие. Это референсы. В сам ролик — только с подписью источника (взять `source_link` из pins.tsv) или если источник — общественное достояние. В публичный репо ничего из `refs/` не коммитить.
- «Похожие пины» без входа Pinterest не отдаёт: `similar` ищет по ключевым словам выбранного пина.
- Из РФ связь с pinterest.com иногда пропадает на 1–2 минуты: скрипт сам повторяет запросы; если не помогло — подождать или включить VPN.

## 3. Путь A — кодом в Remotion (бесплатно)
1. **Ассеты:** PD-гравюры и фото с Wikimedia Commons (API `generator=search`, `gsrnamespace=6`, `iiurlwidth=1600`; записывать в `SOURCES.tsv`) → вырезка `python scripts/cutout.py` (U²-Net) или rembg `isnet-general-use`. Штриховые гравюры вырезаются плохо: их вешать прямоугольником с рваным краем.
2. **Голос черновика:** edge-tts (`pip install edge-tts`; русские голоса `ru-RU-SvetlanaNeural`, `ru-RU-DmitryNeural`; английские `en-US-ChristopherNeural`, `en-GB-RyanNeural`, `en-US-JennyNeural`):
   `edge-tts --voice ru-RU-DmitryNeural --text "<строка>" --write-media voice/s01.mp3`
   Проверка длины каждой строки через ffprobe: **больше 9,7 с — сократить строку и переозвучить, меньше 7,5 с — дописать**. Ускорять `atempo` не больше чем ×1,1.
3. **Тайминги слов:** faster-whisper `word_timestamps=True` → JSON. Ключевое слово сцены = кадр удара (вход вырезки, обводка маркером, штамп).
4. **Сцена = компонент:** фон-бумага (`<Img>` текстуры + полутон кодом) → 2–3 слоя вырезок с разной глубиной (параллакс от `useCurrentFrame()`) → один цветной акцент → маркер (`MarkerCircle` из fx.tsx / SVG `strokeDashoffset`) → камера (scale и translate всего слоя, наезд 1,00→1,08 за сцену).
5. **Fake-oner кодом:** последние 6 кадров сцены — `filter: blur()` + сдвиг по направлению движения; первые 6 кадров следующей — из того же смаза. Склейка без TransitionSeries.
6. **Шаги на двойках** (как у Charlie): держать позу 2 кадра при 24 к/с, а не гладкий easing.
7. **Звук:** голос сверху; бумажный шелест или whoosh на вход вырезки; тик на столбик; штамп или hit на удар; музыка 0,16–0,18 под голосом с даком. Мастер −14 LUFS.

## 4. Путь B — видеогенерация (Higgsfield MCP, ПЛАТНО)
Перед запуском — цена в кредитах и рублях и «да» пользователя (`references/ai-motion-higgsfield.md`).
1. **Ключ стиля:** одна картинка (Nano Banana Pro, формат как у видео). Предложить 3 варианта словами (одна система, разные палитры и композиции), промпт выдать после выбора. Каркас: «editorial mixed-media collage style swatch… archival photo cutouts with rough white paper borders, torn edges, tape, hand-drawn marker circles and arrows, flat color blocks [палитра], paper grain… abstract composition only, no characters, no letters, no words, no numbers, non-photorealistic».
2. **Реквизит-ассеты** для повторяющихся объектов: 1:1 на чистом бумажном фоне с ключом стиля. Прикреплять к каждой сцене, где объект есть, и писать «the X from the reference image».
3. **Промпт сцены** (10 с, ключ стиля прикреплён ВСЕГДА):
   ```
   STYLE REFERENCE: Match the attached style key EXACTLY — <токены стиля>.
   SCENE: <какие вырезки, какой цветной фон, какие пометки/график/карта — образ идеи строки>.
   MOTION: <вход с перелётом + движение камеры + что анимируется; начать и закончить смазом>.
   AUDIO: <фон + 1–2 SFX бумаги/свиста/тика>, no voice, no narration.
   NEGATIVE: readable text, letters, words, numbers, captions, subtitles, watermark, logo,
   photorealism, live-action footage, 3D render, lip-sync, talking characters, color drift.
   ```
   NEGATIVE одинаковый во всех сценах. Для «диорамы»: `No text anywhere except "<СЛОВО>"`.
4. **Длинные промпты-«CRITICAL»** (из промпта на экране рилса): тайминг каждого шота в секундах и «no shot is skipped, merged, shortened or expanded; does not compress into the first third»; блок ON-SCREEN TEXT с запретом всего текста по времени; если текст нужен — шрифт, цвет, высота заглавной и базовая линия в % высоты кадра, «correctly spelled character for character, not attached to any surface»; блок продукта «exactly as shown in @imageN… never changes proportion, colour, label between shots» с физическими размерами.
5. **Модерация:** имена политиков — только в озвучке, не в видео-промпте; лица госдеятелей — средний план + цензурная полоса; «ядерный гриб» и подобное — заменить образом; если платформа предлагает фотореал- или 3D-пресет — отказаться. Две одинаковые неудачи — переписать промпт, а не менять seed.
6. **Сборка:** каждый клип ровно 10 с; голос стартует с 0,25 с; родной звук клипа под голосом ×0,22; `amix normalize=0` → concat. Русский текст, цифры и логотип — кодом поверх (генераторы ломают кириллицу).

## 5. Проверка перед сдачей
- Каждая строка озвучки 7,5–9,7 с, сцены ровно по 10 с.
- Сквозной объект есть в каждой сцене, кадр-«открытие» на месте, вопрос из начала закрыт в конце.
- Удар примерно каждые 3 с (по листу кадров и осциллограмме).
- Ни одной цифры без источника; источники — в подпись к посту.
- Стандартный чек-лист: qa-fit PASS, лист кадров глазами, −14 LUFS, версия «_телефон».
